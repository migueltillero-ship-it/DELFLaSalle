02. Manifeste Institutionnel
Vision 2026

Pourquoi cet écosystème, maintenant ?

L'Alliance Française de San Cristóbal n'opère plus dans un contexte de simple centre d'examen. Elle agit comme opérateur logistique régional du réseau France Éducation International dans le Chiapas, et doit en assumer la rigueur technologique.

Cet écosystème incarne trois engagements :

  • Souveraineté. Code, données et identité visuelle sous contrôle direct de l'AFSC.
  • Conformité. Application stricte du Guide national de communication DELF-DALF 2026.
  • Excellence opérationnelle. Réduction radicale des erreurs GAEL et de la charge administrative.

03. Réponse Institutionnelle

08. Ingénierie Logicielle
Sécurité des flux

Sécurisation des Flux (Architecture Data)

Sans Base Apparente

Les données ne résident pas dans un CMS vulnérable. L'architecture traite le DOM (Document Object Model) en JavaScript, évitant les injections SQL.

Zero SQL

Requêtes Asynchrones

Les soumissions n'actualisent pas la page. Le protocole fetch() envoie un payload JSON chiffré (TLS) vers la passerelle institutionnelle.

AJAX / TLS 1.3

Normalisation Unicode

Le moteur de recherche utilise normalize("NFD"). Il détache les diacritiques (accents, trémas), assurant la correspondance même sans accentuation.

NFD / Diacritiques

Principe de moindre privilège

Le front-end n'expose aucune clé API privée. Toute opération sensible (envoi GAEL, validation tuteur) est déléguée à un endpoint signé, isolé du code public.

09. Extrait de Code
Audit technique

Le Moteur GAEL en clair

Extrait du moteur de vérification orthographique GAEL. La normalisation Unicode garantit qu'une recherche sur « Munoz » retrouve « Muñoz », qu'« Angela » retrouve « Ángela ».

Ce code est auditable publiquement sur le répertoire GitHub : aucune logique cachée, aucune trappe.

  • Tolérance aux fautes d'accent sans baisse de sécurité.
  • Recherche exacte requise sur prénom et nom, jamais de liste publique.
// Normalisation Unicode (NFD) pour la recherche GAEL
const norm = (s) =>
  s.normalize("NFD")
   .replace(/[̀-ͯ]/g, "")
   .toLowerCase()
   .trim();

// Vérification stricte : prénom + nom requis
function findCandidat(prenom, nom) {
  const p = norm(prenom);
  const n = norm(nom);
  return CANDIDATS.find(c =>
    norm(c.prenom) === p &&
    norm(c.nom)    === n
  );
}

11. Sécurisation Logistique — Partie 1

Problématique d'État Civil (GAEL)

Le Diagnostic Opérationnel

Historiquement, les inscriptions manuelles génèrent un pourcentage de fautes de frappe (inversion de lettres, erreurs sur les dates de naissance).

Ces données erronées sont saisies dans GAEL (France Éducation International). Conséquence : les diplômes définitifs, imprimés à Paris et expédiés sous 4 à 6 mois, arrivent avec des erreurs juridiques.

12. Sécurisation Logistique — Partie 2
Le moteur de prévention

Moteur de Prévention (La Solution)

  • Vérification Front-End Autorisée Avant la clôture de la session sur GAEL, l'algorithme JavaScript croise la base de données interne et génère une fiche visuelle affichant exactement l'orthographe qui sera imprimée.
  • Acceptation Légale Numérique Le tuteur doit obligatoirement cocher une case numérique : « Je vérifie que les données sont correctes et je comprends que le diplôme officiel sera émis sur cette base. »
  • Transfert de Responsabilité Cette étape dédouane l'Alliance Française et la Gestion Centrale de toute réclamation future : l'erreur incombe désormais à la validation familiale documentée.
13. Parcours Candidat
User Journey

Du Premier Clic au Diplôme

Le parcours candidat est entièrement scénarisé pour minimiser la friction et maximiser la traçabilité légale. Six étapes, aucune ambiguïté.

Pourquoi 6 étapes ?

Chaque étape génère un évènement archivable. En cas de litige, l'AFSC peut reconstituer le déroulé exact de l'inscription, horodaté, sans contestation possible.

Étape 01 — Découverte

Étape 03 — Vérification GAEL
Affichage de la fiche officielle

Étape 04 — Validation tuteur

14. Cadre Juridique
ARCO & Mineurs

Droits ARCO & Protection des Mineurs

S'agissant d'un public de mineurs, la plateforme est soumise à des normes de confidentialité d'une rigueur absolue.

  • Aucune liste publique. L'accès nécessite Prénom + Noms de famille exacts.
  • Numéro FEI (12 chiffres). Unique identifiant public pour la consultation des notes.
  • Anonymat total. Conformité à la législation mexicaine ARCO et compatibilité RGPD pour FEI Paris.
  • Droit à l'effacement. Toute donnée peut être supprimée sur demande du tuteur légal.
